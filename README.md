#  Планировщик задач (TODO-сервер на Go)

## Описание проекта

Данный проект — веб-сервер на Go с REST API и хранилищем на SQLite, реализующий функциональность планировщика задач (TODO-листа).  
Позволяет:
- Добавлять, получать, редактировать, удалять задачи;
- Отмечать задачи выполненными;
- Использовать правила повторения (например, «каждый день», «каждый год»);
- Искать задачи по тексту и дате;
- Использовать фронтенд через web-интерфейс (папка `web`).

## Выполненные задания со звёздочкой

- **Поиск задач** по подстроке в названии/комментарии и по дате (`search`), реализован.
- **Все базовые API** реализованы: POST, GET, PUT, DELETE для задач, + "отметить выполненной".
- **Сложные правила повторения** (`w`, `m`) — не реализованы.

##  Инструкция по запуску локально

1. Клонируйте репозиторий:
   ```bash
   git clone 
   cd go_final_project
   ```

2. Установите зависимости и запустите сервер:
   ```bash
   go mod tidy
   go run main.go
   ```

3. Откройте браузер по адресу:  
   [http://localhost:7540](http://localhost:7540)

> **Параметры запуска (опционально):**
> - Изменить порт сервера: `TODO_PORT=8080 go run main.go`
> - Изменить файл базы данных: `TODO_DBFILE=mytasks.db go run main.go`

##  Инструкция по запуску тестов

1. В файле `tests/settings.go` по умолчанию параметры такие:
    ```
    const Port = "7540"
    const DBFile = "../scheduler.db"
    var Search = true // для проверки поиска по подстроке и дате
    ```

2. Запуск всех тестов:
    ```bash
    go test ./tests
    ```

3. Запуск отдельных тестов:
    ```bash
    go test -run ^TestAddTask$ ./tests
    go test -run ^TestTasks$ ./tests
    go test -run ^TestTask$ ./tests
    go test -run ^TestEditTask$ ./tests
    go test -run ^TestDone$ ./tests
    go test -run ^TestDelTask$ ./tests
    ```
